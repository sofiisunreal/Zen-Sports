# 🏆 Zen Sports

A modern sports equipment website built using HTML and CSS.  
Zen Sports is designed to showcase athletic products with a clean, responsive, and visually engaging user interface inspired by modern sports brands.

---

## 🚀 Features

- 🏀 Modern sports brand-inspired design
- 📱 Fully responsive layout
- 🎨 Clean and engaging UI
- 🛍️ Product showcase sections
- 🖼️ Hero landing page
- 📂 Organized page structure
- ⚡ Smooth navigation experience

---

## 🛠️ Tech Stack

- HTML5
- CSS3

---

ZenSports/

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sofiisunreal/zen-sports.git
```

Navigate into the project folder:

```bash
cd zen-sports
```

Open the project:

```bash
Open index.html in your browser
```
